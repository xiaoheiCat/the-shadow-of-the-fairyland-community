# 仙界之影

> 天地不仁，以万物为刍狗；
> 大道无形，生育天地。

在此方块构建的须弥芥子之中，重现上古修真图景。
不求闻达于诸侯，但求在此间寻得那一线飞升机缘。

## 【 灵 物 】

世间散落诸多上古遗珍，凡铁难铸，唯机缘可得：

*   **破灭之星**
    九天陨落之残片，蕴含破灭星辰之力。
*   **余烬之阳**
    微尘之中见大日，光华内敛，温养神魂。
*   **命轮之鳞**
    龙之逆鳞，触之必怒，蕴含真龙无上威严。
*   **梦魇之月**
    虚幻与现实的交织，映照人心最深处之魔障。
*   **滞时之冰**
    冻结万古岁月，刹那即是永恒。
*   **风暴剑**
    御风而行，无影无形，斩断三千烦恼丝。

更有 **缘灭花**、**仙羽** 等灵材，静待有识之士发掘。

## 【 道 途 】

*   **境界**
    吸纳天地灵气，突破肉身桎梏。从凡夫俗子到陆地神仙，唯有一心向道。

*   **机缘**
    天道酬勤。无论是每日的修行功课，还是静坐感悟，皆有福报降临。

*   **试炼**
    灵气复苏，世间生灵亦受其泽，实力大增。非大毅力、大神通者，不可轻敌。

*   **幻音**
    虚空之中，时有异界魔音贯耳，似狂歌，似叹息，皆为红尘幻象，乱我道心。

## 【 启 灵 】

欲入此门，需备 **NeoForge** 之基石。
将此法门 (Mod) 置入天地法则 (mods) 之中，重启混沌，即可踏上仙途。
